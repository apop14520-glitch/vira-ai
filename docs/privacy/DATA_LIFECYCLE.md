# Ciclo de vida de dados

## Estado atual

Não há coleta, persistência ou processamento de dados pessoais. SQLite existe apenas como adapter local preparado para desenvolvimento.

## Fluxo futuro

Qualquer novo dado deverá passar por: finalidade e base legal, minimização, classificação, validação, armazenamento segregado por categoria e organização, acesso de menor privilégio, retenção documentada, auditoria, anonimização/eliminação e eventual exportação.

Requests de eliminação, exportação, anonimização, registros de consentimento e registros de base legal serão tratados como capacidades próprias da plataforma, nunca como lógica espalhada nos módulos de produto.
